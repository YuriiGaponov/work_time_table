# PET-проект work_time_table

## Описание проекта

**work_time_table** — это Flask-приложение для учета рабочего времени сотрудников. Оно позволяет автоматизировать процесс создания табеля учета рабочего времени, используя данные из производственного календаря и информацию о сотрудниках.

## Основные функции

-   **Получение производственного календаря** из внешнего источника для корректного учета рабочих и выходных дней.
    
-   **Хранение данных сотрудников**, включая личные данные и рабочие графики.
    
-   **Создание табеля учета рабочего времени** с возможностью сохранения в форматах:
    
    -   Open Document Text (.odt)
        
    -   Microsoft Word (.docx)
        
-   **Импорт данных сотрудников** из файлов:
    
    -   Microsoft Excel (.xlsx)
        
    -   CSV
        

## Требования для запуска

Для работы приложения необходимо установить следующие зависимости:

-   Python 3.13
    

## Инструкция по установке

Клонируйте репозиторий:
    
    git clone https://github.com/YuriiGaponov/work_time_table.git

    
Установите зависимости:
    
    pip install -r requirements.txt

    
Настройте конфигурацию приложения в файле `config.py`.
    
Запустите приложение:
    
    flask run 

## Использование приложения

-   Перейдите по адресу [http://127.0.0.1:5000/](http://127.0.0.1:5000/) в вашем браузере.
    
-   Используйте интерфейс для добавления и редактирования сотрудников, создания табелей и экспорта данных.
    

## Примечание

Приложение использует внешние API для получения производственного календаря, поэтому убедитесь, что у вас есть доступ к этим сервисам. Также проверьте настройки безопасности при работе с данными сотрудников.
